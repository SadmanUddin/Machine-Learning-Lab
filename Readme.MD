# MACHINE LEARNING LAB

A repository where I practice and explore different machine learning algorithms using Python and Jupyter Notebook.

I work with different datasets, train models, evaluate their performance, experiment with hyperparameter tuning, and compare different models to understand how they perform.

## Topics Covered

### 1. Supervised Learning

- **Regression:** Linear Regression, Polynomial Regression
- **Classification:** Logistic Regression, K-Nearest Neighbors (KNN), Decision Trees

### 2. Unsupervised Learning

- **Clustering:** K-Means and other clustering algorithms

### 3. Model Development & Evaluation

- **Model Evaluation:** Accuracy, Precision, Recall, F1-score, MAE, MSE, R²
- **Cross-Validation:** K-Fold Cross-Validation
- **Hyperparameter Tuning:** Grid Search, Randomized Search
- **Model Comparison:** Training and comparing different models based on their performance.

Each topic has its own Jupyter Notebook containing practical implementations, model training, experiments, evaluations, and comparisons.

## Technologies & Libraries

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SadmanUddin/Machine-Learning-Lab.git
```

### 2. Navigate to the project directory

```bash
cd Machine-Learning-Lab
```

### 3. Install dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```
